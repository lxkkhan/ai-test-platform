# 测试全生命周期图

## 一、测试全生命周期总图

```mermaid
graph LR
    subgraph 计划阶段
        P1[需求评审] --> P2[测试计划]
        P2 --> P3[测试设计]
    end

    subgraph 设计阶段
        D1[tapd-analyze<br/>需求分析]
        D2[design-analyze<br/>设计稿提取]
        D3[neo4j-scanner<br/>页面扫描]
        D1 --> D3
        D2 --> D3
        D3 --> D4[neo4j-gen<br/>测试点生成]
    end

    subgraph 开发阶段
        C1[tapd-gen<br/>用例生成]
        C2[template-engine<br/>脚本组装]
        C1 --> C2
    end

    subgraph 执行阶段
        E1[ai-test-executor<br/>自动执行]
        E2[dom-recorder<br/>手动录制]
        E1 --> E3[截图/判定]
        E2 --> E3
    end

    subgraph 报告阶段
        R1[tapd-sync<br/>结果回写]
        R2[tapd-notify<br/>通知推送]
        R3[verification-reporter<br/>验证报告]
        R1 --> R2
        R1 --> R3
    end

    subgraph 缺陷阶段
        B1[tapd-bug<br/>自动提Bug]
        B2[TAPD 开发修复]
        B1 --> B2
        B2 --> E1
    end

    P3 --> D1
    D4 --> C1
```

## 二、测试生命周期与 Skills 对应表

| 阶段 | 活动 | 对应 Skill | 产出 |
|------|------|-----------|------|
| ① 计划 | 需求评审 | tapd-analyze | 需求结构化分析 |
| ② 设计 | 设计稿提取 | design-analyze | 字段约束/业务规则 |
| ③ 设计 | 页面扫描 | neo4j-scanner | Module→Page→Field 图谱 |
| ④ 设计 | 接口分析 | apifox-sync | OpenAPI 规范 |
| ⑤ 开发 | 用例生成 | tapd-gen | TAPD 测试用例 |
| ⑥ 开发 | 脚本组装 | template-engine | Playwright 脚本 |
| ⑦ 执行 | 自动执行 | ai-test-executor | 测试结果+截图 |
| ⑧ 执行 | 手动录制 | dom-recorder | 操作回放脚本 |
| ⑨ 报告 | 结果同步 | tapd-sync | TAPD 用例状态更新 |
| ⑩ 报告 | 通知推送 | tapd-notify | 企微报告 |
| ⑪ 报告 | 验证报告 | verification-reporter | 字段级比对报告 |
| ⑫ 缺陷 | Bug提报 | tapd-bug | TAPD Bug + 关联需求 |
| ⑬ 编排 | 全流程 | tapd-executor/tapd-test | 一键全自动 |

## 三、数据流转图

```mermaid
graph LR
    subgraph 数据源
        S1[TAPD] --> S2[CoDesign]
        S3[线上系统] --> S2
    end

    subgraph 结构化存储
        S2 --> N1[Neo4j 图谱]
        N1 --> N2[(Module)]
        N1 --> N3[(Page)]
        N1 --> N4[(Area)]
        N1 --> N5[(Field/Button)]
        N1 --> N6[(TestCase)]
    end

    subgraph 执行数据
        N6 --> X1[.ai-test-runs/]
        X1 --> X2[manifest.json]
        X1 --> X3[results.json]
        X1 --> X4[screenshots/]
        X1 --> X5[report.html]
    end

    subgraph 回写
        X3 --> T1[tapd-sync → TAPD]
        X3 --> T2[tapd-bug → TAPD Bug]
    end

    subgraph 可视化
        N1 --> D1[仪表盘 localhost:3344]
        X5 --> D2[HTML 报告]
    end
```
