# Verification Reporter — 设计稿 vs 系统自动验证报告

## 功能概述

从 TAPD 需求详情中读取设计规格（详细字段设计表、操作按钮、测试要点），
自动登录 SIT 系统，逐条验证字段是否存在、控件类型、文本长度、必填标记、默认值，
并对操作按钮类和保存类测试点自动执行，最终生成 pytest-html 风格的 HTML 验证报告。

## 触发方式

### 命令式

```
/verification-reporter <story_id>      # 对指定需求生成验证报告
/verification-reporter 1026058         # 示例：预算政策管理-自制
```

### 对话式

"生成 1026058 的验证报告"、"校验这个需求的字段"、"对比设计稿和系统的差异"

## 工作流

### 第一步：读取 TAPD 需求

从 TAPD API 获取需求详情（description HTML），解析出：

| 数据 | 来源 | 说明 |
|------|------|------|
| 详细字段设计表 | TAPD description 中的 HTML 表格 | 字段编码、显示名称、类型、长度、必填、参照节点、备注 |
| 操作按钮 | TAPD description 中的 `<h5>操作按钮</h5>` 段落 | 所有操作按钮名称列表 |
| 测试要点 | TAPD description 中的测试要点表格 | 测试场景、类型、验证点 |

### 第二步：系统登录与导航

1. 通过 CDP 启动真实 Chrome（复用 `.auth/chrome-profile-yxxt` 登录态）
2. 自动登录 SSO → 选择营销系统 SaaS-SIT
3. 侧边栏搜索"预算政策" → 键盘选择 → 回车
4. 点击"新增" → 点击"增行"展开明细表

### 第三步：DOM 字段扫描

| 扫描内容 | 方式 | 说明 |
|---------|------|------|
| 主表单字段 | Ant Design form-item 解析 | 获取标签文本、控件类型、必填标记、默认值 |
| 明细表字段 | VLM 截图识别 + DOM 降级 | 扫描表格表头列名 |
| 系统按钮 | DOM 扫描所有 button + VLM 补充 | 提取工具栏按钮列表 |

### 第四步：字段校验

每条校验输出为一条测试用例（TC-VALID-xxx）：

| 校验项 | 方式 | 判断逻辑 |
|--------|------|---------|
| 字段是否存在 | normalize 匹配 | 设计稿名称 vs 系统标签 |
| 控件类型 | DOM 检查 | 下拉选择/日期/文本框 vs 设计稿要求 |
| 文本长度 | maxlength 属性 或 极值输入测试 | 输入超长文本，检查截断或错误提示 |
| 必填标记 | CSS 类检查 | label 含 `*` 或 `ant-form-item-required` |
| 默认值 | 读取 input.value | 设计稿备注有"默认"的字段 |
| 参照节点 | 检查弹窗类型 | 引用节点名称匹配 |

### 第五步：测试点自动执行

根据测试点类型分发执行：

| 类型 | 执行方式 | 示例 |
|------|---------|------|
| 操作按钮 | 点击按钮 → 检查页面反馈 | 增行/删行/保存 |
| 字段校验-必填 | 点击保存 → 检查错误提示 | 不填必填字段保存 |
| 其他类型 | 标记为"需人工验证" | 权限/唯一性/异常 |

### 第六步：生成 HTML 报告

pytest-html 风格，包含：

```
┌─────────────────────────────────────────────────────┐
│  ✅ 141 total  ✅ 64 passed  ❌ 32 failed  ⏭️ 48 blocked │
├─────────────────────────────────────────────────────┤
│  Environment                                        │
│  System: 营销系统 SaaS-SIT                           │
│  TAPD: 1162721303001026058                           │
├─────────────────────────────────────────────────────┤
│  各模块通过率（柱状图）                                 │
│  字段对应-表头 ████████████████░░ 88%                │
│  字段校验-必填 ██████░░░░░░░░░░░░ 33%                │
│  ...                                                 │
├─────────────────────────────────────────────────────┤

│  │  # │ ID          │ Name     │ Result │      │    │

```

## 注意事项

1. **登录态**：Profile 目录约 7 天过期，过期后需重新手动登录一次
2. **测试点阻塞**：权限/唯一性/异常类测试点标记为"需人工验证"，不自动执行
3. **明细表字段**：依赖 VLM 截图识别，当前只能捕获可见列（约 5/19）
4. **CDP 端口**：默认 9222，与其他脚本共用时注意端口冲突
5. **独立运行**：脚本不修改任何其他 skills 文件，仅引用 node_modules 和 .env
